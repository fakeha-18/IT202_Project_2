# IT202 Project 2 – Moving On Up

**Fakeha Irfan**

## About My Project

For Project 2, I continued working on my Moving On Up website from Project 1. The main goal of this project was to take the login form I already created and build on it using PHP and MySQL.

In Project 1, I used JavaScript to check the representative's login information. For this project, I worked on connecting that information to a database so the website could handle client accounts and moving events.

## What I Included

My project includes the representative login page, client information, moving event bookings, cancellations, and special instructions for moves. I also included the MySQL tables for representatives, clients, moving information, and special instructions.

I kept the same general website design from Project 1 and added the PHP files needed for the database features.

## Project Files

- `index.php` – Main login page and website functions
- `functions.php` – PHP functions used throughout the project
- `db.php` – Database connection code
- `config.php` – Database configuration (password placeholder only)
- `assets/` – CSS and JavaScript files
- `database/` – SQL setup file and sample CSV records
- `original_project1.html` – Original Project 1 login page
